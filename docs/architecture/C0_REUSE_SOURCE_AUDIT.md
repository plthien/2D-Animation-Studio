# C0 targeted reusable-source audit

Audited against PR #1's 2026-10-15 source tree, not directory prefixes. The 813-row ledger remains the source of truth for all baseline paths; this report documents high-risk boundaries where retaining a **behavior** differs from keeping an obsolete product owner. C2 extracts/replaces them; C0 does not change production.

**Entrypoint checks:** `app/main.py:create_app` imports platform, authoring, artifact and legacy routing. V4 worker code may be reached through its registered production routers/jobs but that alone does not justify KEEP; ledger reachability is distinct from reuse classification. `src/App.tsx:Shell` imports channels/projects/studio pages and shared cockpit layout. Windows launchers and V4 FFmpeg process ownership are runtime/worker dependencies and require explicit C2 extraction before any legacy deletion.

**Limit:** This is source-level classification evidence, not execution of C2 extraction. Tests named in the ledger are future owner acceptance tests, not already-running C0 suites. No new test-per-file suite was added.
