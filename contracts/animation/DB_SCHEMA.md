# Animation database contract (frozen C0 proposal)

Default URL is `sqlite:///./2d_animation_studio.db`. Fresh migration `0001_animation_initial` creates exactly the fourteen tables below plus Alembic's `alembic_version`; later revisions begin `0002`. SQLite types: IDs/hashes/timestamps/statuses are `TEXT`, counters `INTEGER`, booleans `INTEGER CHECK (value IN (0,1))`, bounded JSON `TEXT` containing canonical JSON, and bytes metadata is `INTEGER`. All timestamps are UTC RFC3339 text. `PRAGMA foreign_keys=ON`, WAL and a bounded busy timeout are mandatory.

## CAS, deletes, and legacy refusal

The sole publication owner opens the transaction; callers with an already-flushed write must receive a typed precondition error instead of entering a nested `BEGIN IMMEDIATE`. It validates ownership, immutable bytes and fingerprints, inserts the artifact, and CAS-updates a stage head at expected revision. A loser receives `409 STALE_HEAD`; its valid orphan bytes are retained for reconciler inspection, never overwrite another head. Do not hold SQLite write transactions across provider/network/large-file I/O.

At startup C2 inspects configured SQLite metadata before migration. Presence of known YTB tables or an old Alembic revision raises `LEGACY_DATABASE_UNSUPPORTED` without opening a write transaction; users must choose a new path. No old DB is altered, dropped, imported, or migrated.
